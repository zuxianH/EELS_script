# Scoped lessons

The Arrhenius BTO preparation and periodic-oxygen-center lessons are scoped to
the recorded engine/model/test conditions. They do not validate other sites or
long-time finite-temperature behavior. Add separate JSON records matching the
event schema, with exact tool/build versions and
conditions in `scope`. A criterion and evidence are necessary but must still be
reviewed for adequacy. Keep uncertain explanations as hypotheses in task events.
`rw context` includes verified lessons only for matching project/global and
site/global scopes; it does not convert them into instructions or release gates.
